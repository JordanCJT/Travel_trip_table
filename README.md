# 行程表

一个不需要服务器的行程网页：时间表、地址、备注、路线地图，以及可以直接复制到 WhatsApp 群的每日行程文字。一个网站可以放很多次旅行，每次旅行有自己的名字、出发日期和天数。

## 文件

- `index.html` 网页本身
- `itinerary.xlsx` 网页默认显示的行程（包含全部旅行）
- `vendor/xlsx.full.min.js` 读取和导出 Excel 用的库（不要删）
- `.nojekyll` 让 GitHub Pages 原样发布文件

## 放到 GitHub 上（只做一次）

1. 登录 github.com，点右上角 “+” → New repository，起个名字（例如 `trips`），选 Public，创建。
2. 在新仓库页面点 “uploading an existing file”（或 Add file → Upload files），把这个文件夹里的所有文件拖进去。`vendor` 文件夹和 `.nojekyll` 也要上传。点 Commit changes。
3. 进入仓库的 Settings → Pages。Source 选 “Deploy from a branch”，Branch 选 `main`，文件夹选 `/ (root)`，点 Save。
4. 等 1 到 2 分钟，页面顶部会出现网址，格式是 `https://你的用户名.github.io/trips/`。把这个网址发到 WhatsApp 群。

注意：Public 仓库任何人知道网址都能看到行程。航班号、酒店订单这类私人信息请不要写进表格。

## 多次旅行

- 页面最上面的“旅行”下拉框可以切换不同的旅行。
- 点“＋ 新建旅行”新建一次旅行，然后直接改名字、出发日期和天数。天数可以随时改。如果后面几天已经有行程，天数不能小于最后一个有行程的那天。
- 点“删除这个旅行”（要点两次确认）可以删掉当前旅行，删除后几秒内可以撤销。
- 每次旅行的日期和星期，都按它自己的出发日期推算。

## 修改行程

1. 打开网页，点“编辑”页。点“添加一行”添加，直接在格子里改，点“删除”删掉（几秒内可以撤销）。
2. 改动会**自动保存在这台设备的浏览器里**。刷新、关掉再打开都还在。
3. 家人用自己的手机或电脑打开同一个网址，看到的是网站上的版本。每个人的修改只保存在自己的设备上，不会互相同步。
4. **要让所有人看到你的修改：** 在“编辑”页点“导出 Excel（全部旅行）”，得到 `itinerary.xlsx`。到 GitHub 仓库里 Add file → Upload files，上传这个文件覆盖旧的，1 到 2 分钟后同一个网址就会显示新内容。
5. 想放弃自己设备上的修改，点页面上方黄色提示里的“恢复为网站版本”。

注意：清除浏览器数据，或换了设备，设备上保存的修改会丢失。重要的修改请记得导出 Excel 备份。

## 复制到 WhatsApp

改好行程后，打开网页的“分享文字”，可以选择是否显示地址和备注，然后点“复制这一天”或“复制全部行程”，粘贴到 WhatsApp 群。

## 表格怎么填

Excel 里有两个工作表：

- **行程**：每一行是一个景点、一餐、一个住宿或一段交通。列是：旅行、天数、日期、时间、类别、地点、城市、地址、备注、纬度、经度。地点必填，其他可以留空。“旅行”要和“设置”里的名字一致。
- **设置**：每次旅行一行，填旅行名称、出发日期（例如 2026-12-23）和天数。

类别可选：景点、早餐、午餐、晚餐、住宿、交通、其他、标题。“标题”那一行的地点是当天标题，备注是说明。时间可以填 09:30，也可以填 上午、下午、傍晚、全天，没填时间的按表格里的先后顺序。

也可以在“编辑”页点“导入表格”，选择 Excel 或 CSV 文件，或者复制表格内容粘贴进去。
